# Agent Instructions

## Context

Read `README.md` before making any changes. It describes what the project does,
how it's configured, and how it works.

## CHANGELOG.md

Every change that affects behavior, structure, or documentation **must** be
recorded in `CHANGELOG.md`. Add a bullet under the `[Unreleased]` section with
a brief description of what changed and why. Group entries under `### Fixed`,
`### Added`, `### Changed`, or `### Removed` headings as appropriate.

## README.md

`README.md` is the primary source of truth for users. If your changes affect
setup, configuration, environment variables, behavior, or testing, update
`README.md` to match. Keep it accurate and concise.
